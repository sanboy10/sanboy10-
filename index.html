Panasea Coffee Hotspot

Rancangan Layanan Internet (Hotspot Cafe / Area Komersial)

1. PROFIL & IDE USAHA

Nama Layanan: Panasea Coffee Hotspot

Masalah di Lapangan: Wi-Fi cafe biasa sering lambat saat banyak pengguna, sinyal tidak menjangkau seluruh area cafe, koneksi tidak stabil, serta pengunjung butuh jaringan yang aman.

Solusi & Inovasi: Penerapan sistem voucher atau login terpusat menggunakan captive portal agar penggunaan bandwidth lebih teratur, adil, serta manajemen bandwidth otomatis pada router.

2. RANCANGAN TOPOLOGI & DESAIN VISUAL

Skema Jaringan:

ISP (Sumber Internet) → Router (MikroTik) → Switch / Access Point → Perangkat User (HP/Laptop)

Alur Login Pengguna:

User konek Wi-Fi → Muncul halaman login/captive portal → Masukkan kode voucher → Internet aktif

4. RENCANA IMPLEMENTASI & TEKNIS

Langkah Konfigurasi:
  1. Setting IP & jaringan di MikroTik.
  2. Konfigurasi Hotspot Server & halaman login (Captive Portal).
  3. Pengaturan Manajemen Bandwidth (Agar pembagian kecepatan adil antar pengguna).
Mitigasi Masalah & Solusi Gangguan:
  • Saat Listrik Padam: Menggunakan Mini DC UPS atau UPS standard agar router dan access point tetap menyala.
  • Saat Router Hang / Overload: Mengaktifkan fitur auto-reboot terjadwal di MikroTik dan menyediakan tombol reset/power eksternal untuk staf.
  • Gagal Koneksi / ISP Utama Putus: Menyiapkan backup koneksi seluler (Failover 4G/5G) pada port MikroTik.
  • Keamanan Jaringan: Mengaktifkan fitur Client Isolation di Access Point untuk mencegah pencurian data antar pengguna.
